# Run EyeGaze Communication

On Windows, launch Preview-Windows.cmd or use the project environment from VS Code:

    .\.venv\Scripts\python.exe run.py

This opens the webcam, calibration and the communication screens. Mouse clicks also work on cards. For a deliberate mouse-only session use run.py --mouse-only.

In Settings, choose a category and enter a name in one language tab. Known names such as Upma fill the other two tabs. For an unfamiliar concept enter the missing translations and review the sentences. A spoken-sentence override applies only to its own language. Review the suggested picture, pick another symbol, or supply a PNG/JPEG. Save once to store the three labels, three locally generated voice clips and one shared picture. Linked translations are deleted together after confirmation.

Patients choose their normal category, then the card using gaze. Use Next for later pages. My cards is an optional shortcut. Existing single-language cards stay available; to publish equivalent versions, re-enter the old label in the same category and review each translation and sentence before saving.
